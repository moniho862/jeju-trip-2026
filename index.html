每日行程

島上行程使用韓國時間（比台灣快 1 小時）。以四人租車估算，車程含彈性，當天以 Naver Map 路況為準。餐廳可直接點店名對應的地圖，出發前再看店休與臨時公告。

12/11（五） · 西海岸

從涯月慢慢開到翰林

紅眼班機落地後先吃早餐、休息，再看海。

如果沒睡好，跳過涯月步道或午餐後提早休息。16:00 前要寄放行李，先向飯店確認。
  1. 06:05–07:40

    抵達濟州國際機場

    入境、領行李，再依訂單搭租車接駁。

    Naver Map ↗
  2. 07:40–09:00

    租車取車

    安排可在早上 9 點前交車的方案。租車商尚未選定，以訂單上的接駁與取車地址為準。

  3. 09:15–10:00

    金喜善濟州馬尾藻湯

    早餐吃濟州傳統馬尾藻豬骨湯（몸국）。地址：제주시 어영길 45-6。

    Naver Map ↗
  4. 10:45–11:35

    涯月・漢潭海岸散步路

    從早餐店開往涯月，留約 45 分鐘含停車。沿著玄武岩海岸散步，風大就縮短。

    Naver Map ↗
  5. 11:45–13:00

    Nolman 海鮮拉麵

    漢潭步道附近吃海鮮拉麵。地址：제주시 애월읍 애월로1길 24。

    Naver Map ↗
  6. 13:40–14:30

    挾才海水浴場

    涯月開往挾才約 30–40 分鐘，看飛揚島、拍海岸照。

    Naver Map ↗
  7. 14:30–15:45

    Comma Café 쉼표

    挾才海邊喝咖啡、看飛揚島。地址：제주시 한림읍 협재리 1732。

    Naver Map ↗
  8. 16:00–17:30

    阿吉拉酒店入住

    到翰林飯店辦理入住，回房休息。

    Naver Map ↗
  9. 18:00–19:30

    잉겅 翰林挾才黑豬肉

    四人分食濟州黑豬肉、帶骨豬排。地址：제주시 한림읍 한림로 333。

    Naver Map ↗
12/12（六） · 9.81 PARK・西南

重力賽車、茶園與山茶花

睡飽再去涯月玩賽車，下午走西南部，晚餐到西歸浦市場。

先確認四人的 RACE 981 場次、票種和乘坐限制。戶外賽道若因天候暫停，可改玩園區室內設施。天地淵瀑布列為機動加站。
  1. 08:45–09:50

    阿吉拉酒店出發去涯月

    早餐可前晚先備好，在房內吃完再出發。這段預留車程、停車與報到。

    Naver Map ↗
  2. 10:00–12:00

    9.81 PARK 濟州・RACE 981 重力賽車

    預留兩小時給四人報到、排隊和體驗。此為預排時段，冬季營運與場次以樂園公告為準。

    Naver Map ↗ 9.81 PARK 官網・查場次 ↗
  3. 12:00–12:50

    Broccollege 브로콜리지

    就在 9.81 PARK 園區內用午餐，吃完再開往茶博物館。地址：제주시 애월읍 천덕로 880-24。

    Naver Map ↗
  4. 13:20–14:20

    O’Sulloc 茶博物館

    逛茶館、喝抹茶、看茶田。

    Naver Map ↗
  5. 14:45–16:00

    山茶花之丘

    走冬季山茶花步道，花況視當週而定。

    Naver Map ↗
  6. 16:45–17:30

    天地淵瀑布（選去）

    若賽車或花園停留較久，直接前往市場。

    Naver Map ↗
  7. 17:45–19:00

    西歸浦每日偶來市場

    市場指定停靠：中央通닭（중앙통닭），點蒜味炸雞，四人分食。地址：서귀포시 중앙로48번길 14-1。

    Naver Map ↗ 中央通닭・Naver Map ↗
  8. 20:15 左右

    回翰林飯店

    西歸浦 → 翰林估約 60–75 分鐘，視路況調整。

    Naver Map ↗
12/13（日） · 濟州東線

城山日出峰與涉地可支

東線離飯店最遠，早上出發，下午提早回程。

遇強風、大雨或步道管制，可改 Aqua Planet Jeju。東線車程長，先查即時路況，也可以只走日出峰山腳。
雨天備案・Aqua Planet Jeju ↗

    飯店出發・往城山

    Naver Map ↗
  2. 10:00–11:35

    Naver Map ↗
  4. 13:10–14:15

    涉地可支

    Naver Map ↗
  5. 14:40–15:20

    Café The Light 카페더라이트

    喝咖啡、看城山海景，再開回翰林。地址：서귀포시 성산읍 한도로 269。

    Naver Map ↗
  6. 15:20–17:20

    開回翰林

    跨島回程預留約兩小時。

    Naver Map ↗
  7. 18:00–19:30

    挾才海女之家 협재해녀의집

    四人可分食辣燉帶魚或海鮮拼盤。地址：제주시 한림읍 협재3길 19。

    Naver Map ↗
12/14（一） · 濟州市區

買伴手禮，晚班機回台

退房後一路往機場方向走，晚餐後還車。

若市區塞車或排隊，先跳過觀德亭。以 19:15 抵達航廈為目標，還車地點與末班接駁時間先向業者確認。

    阿吉拉酒店整理行李・退房

    Naver Map ↗

    Naver Map ↗
